# 日程组件 形态草图

> 用途：给你一眼看清这个组件做出来长什么样。
> 说明：**下面是示例数据**（我没读你的真实日历——读授权日历需要你在 App 里点同意）。装上 App 并授权后，同样的位置显示的就是你自己的日程。
> 时间基准：2026-10-22 周四 06:15（画图时刻）。

---

## 1. 胶囊态 · 横排（Dock 在屏幕底部，最常用）

Dock 上方左右两侧的空白处，和「待办」「时钟」并排：

```
      ┌─────────────┐  ┌──────────────────────────────┐  ┌──────────┐
      │  06:15      │  │ 09:00  产品面试·字节跳动    │  │  待办    │
      └─────────────┘  └──────────────────────────────┘  └──────────┘
         ↑时钟              ↑日程组件                          ↑原有组件
```

四种状态长这样：

```
即将开始（距开始 > 15min，无尾标）
  09:00  产品面试·字节跳动

快开始了（≤ 15min，尾标倒计时，每 60 秒刷新）
  09:00  产品面试·字节跳动    ▸ 12m

正在进行（绿点 + 「进行中」+ 剩余时长）
  ● 进行中  产品面试·字节跳动    ▸ 25m

今天没有日程
  暂无日程
```

时间超过今天：

```
  明天 10:00  二面·某公司
  周五 14:30  谈薪
```

标题太长会**在固定宽度里循环滚动**（和待办卡片的滚动是同一条实现）。

---

## 2. 胶囊态 · 竖排（Dock 拖到屏幕左边或右边）

横向空间只剩 Dock 那点宽度，所以换成「环 + 一行字」：

```
     ╭───╮
     │ 3 │      ← 环心 = 今天还剩几件事
     ╰───╯
    09:00        ← 下一场的时间
```

- 外环是**今天已过的比例**（00:00 → 24:00 走一圈），和番茄钟/待办同一套环
- 未授权时环心显示 `?`
- 进行中时下面那行显示「进行中」

---

## 3. 鼠标悬停 → 展开今日时间轴（340pt 浮层）

鼠标移到胶囊上就浮出来，移开 0.35 秒后收起：

```
┌────────────────────────────────────────────┐
│ 10月22日 周四 · 5 项   1 进行中        ⤢  │  ← ⤢ 打开完整窗口
│ [全部] [工作] [求职] [个人]                │  ← 点日历名筛选
├────────────────────────────────────────────┤
│ 全天                                       │
│ ■ 全天 · 投递截止                          │
├────────────────────────────────────────────┤
│ 09:00 – 10:00   产品面试·字节跳动      ■  │
│ 11:30 – 12:00   回邮件                 ■  │
│ ● 14:30 – 15:30 产品面试·二面          ■  │  ← 进行中整行高亮
│ ─────────────────────────────────── ● ──  │  ← 「现在」分隔线
│ 16:00 – 17:00   谈薪                   ■  │
│ 18:00 – 19:00   健身                   ■  │
├────────────────────────────────────────────┤
│ ＋ 添加日程…                               │
└────────────────────────────────────────────┘
```

细节：
- 已经过去的事件**变淡**（opacity 0.4），一眼看出还剩哪些
- 鼠标划到某一行，行尾出现 `×` 可删；点行本身进去改
- 底部 `＋ 添加日程…` 直接新建
- 日历名可以点，比如只想看「求职」，点掉其他

```
├────┬──────┬──────┬──────┬──────┬──────┬──────┬────┤
│    │ 一   │ 二   │ 三   │ 四●  │ 五   │ 六   │ 日 │
│    │10/19 │10/20 │10/21 │10/22 │10/23 │10/24 │10/25│
├────┼──────┼──────┼──────┼──────┼──────┼──────┼────┤
│ 09 │      │      │      │█面试 │      │      │    │
│ 10 │      │      │      │      │      │      │    │
│ 11 │      │      │      │      │      │      │    │
│ 12 │      │      │      │      │      │      │    │
│ 13 │      │      │      │      │      │      │    │
│ 14 │      │      │      │█二面 │      │      │    │
│ 15 │      │      │      │      │      │      │    │
│    │ ...                                    │    │
├────┴────────────────────────────────────────┴────┤
│ 4 条本周日程 · 1 条本地    导出▾  导入…  访达  清空│
└────────────────────────────────────────────────────┘
```

- 今天那列头上有绿点
- 事件块左边一条日历色竖条，和系统「日历」里的颜色对应
- 空白处**双击**＝在那个小时新建
- 跨午夜的事件（23:00–次日 01:00）在结束那天画到底，带 `≫` 角标（产品定的简化方案，一期不做跨列拼接）
- 底部可以导出 JSON / ICS / Markdown，或清空本地数据

## 6. 关键行为（你最关心的几条）

| 情况 | 组件怎么表现 |
|---|---|
| 第一次装，没授权日历 | 胶囊显示「授权日历」，点一下弹系统框，一步到位 |
| 你拒绝授权了 | **不报错**，自动改用本地保存的日程，设置页里有一行提示，可以关掉不再烦你 |
| 本地数据文件坏了 | 当空的处理，重建成空文件，不崩 |
| 今天没日程 | 胶囊「暂无日程」，浮层里「今天没有日程，享受空白吧」 |
| 跨过半夜 0 点 | 下一次刷新自动重算，进度环清零 |
| Dock 从底部拖到侧边 | 自动切成竖排紧凑版，字号也跟着 Dock 粗细走 |
| 字号整体调小到 70% | 胶囊里所有尺寸等比缩，不会挤成一团 |
